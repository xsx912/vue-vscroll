# 测量用 ResizeObserver 持续观察，未测行用固定估算值、不自校准

动态模式下两个易被"修复"的刻意选择：

1. **ResizeObserver 持续观察已渲染行**，而不是挂载时测一次：图片加载完成、内容展开、视口变宽导致换行增多，行高都会自动跟进。观察器构造器像 `intersectionObserver` 一样可作为 prop 注入（jsdom 无此 API，测试需要打桩）。

2. **未测行一律用 `estimatedItemSize` 固定估算，不用已测行平均值自校准**：估算值自校准会让 totalSize 随测量进度漂移，滚动条"呼吸"跳动，且平均值的更新时机难以测试。代价是未测区域首滚位置略不准——由锚定修正和两阶段跳转兜底，而不是让估算值动。

拒绝"先离屏测准再滚"：为边缘精度引入一整套隐藏测量 DOM，复杂度不成比例。
